# Global Olympic Sports Performance Analysis

A Tableau project that analyzes Olympic Games data to understand medal distribution, participation by country, and participation across sports.

## Objective
To study Olympic athlete data and show it through clear visualizations, a dashboard and a story, so that patterns in medals, countries and sports are easy to understand.

## Tools Used
- Tableau (Desktop / Public)
- CSV dataset
- GitHub

## Dataset
- File: `athlete_events.csv`
- Source: [paste the dataset link here, e.g. Kaggle "120 years of Olympic history"]
- Main columns: ID, Name, Sex, Age, Height, Weight, Team, NOC, Games, Year, Season, Sport, Event, Medal

Note: The dataset is not included in this repository. Please download it from the source above.

## Visualizations
1. **Medal Analysis**: bar chart comparing Gold, Silver and Bronze medal records.
2. **Olympic Participation by Country**: horizontal bar chart of participation by NOC code.
3. **Sports Participation**: bar chart showing how often each sport appears in the data.

## Dashboard
The dashboard combines all three visualizations on one screen, so medals, country participation and sports participation can be compared together.

## Story
The Tableau Story presents the dashboard as a story point with a caption, explaining the findings step by step.
